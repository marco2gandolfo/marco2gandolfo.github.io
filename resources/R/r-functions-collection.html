R Functions collection

Here is a collection of the R functions described in the various tutorials:

  1. Shift position of an object in an image - https://github.com/marco2gandolfo/rcourse/blob/main/shiftobj.R
  2. Create a zoomed-in version of one or many images (e.g. for a BE experiment) - https://github.com/marco2gandolfo/rcourse/blob/main/zoom_in_image.R
  3. Add image to canvas of desired size without altering ratio - https://github.com/marco2gandolfo/rcourse/blob/main/resizecanvas.R
  4. Scramble object images and add a grid to them - https://github.com/marco2gandolfo/rcourse/blob/main/gridandscramble.R
  5. Find outliers - https://github.com/marco2gandolfo/rcourse/blob/main/Out_Classifier.R
  6. Area under the curve for metacognitive sensitivity - https://github.com/marco2gandolfo/rcourse/blob/main/auroc2R.R
  7. Signal detection theory classifier - https://github.com/marco2gandolfo/rcourse/blob/main/SDT_Classifier.R
  8. Shrink images - https://github.com/marco2gandolfo/rcourse/blob/main/shrink_images.R
  9. Flip images - https://github.com/marco2gandolfo/rcourse/blob/main/flip_images.R
  10. Reverse videos - https://github.com/marco2gandolfo/rcourse/blob/main/reverse_videos.R
  11. Find coordinates of the bounding box surrounding an object on a neutral background - rcourse/find_obj_coordinates.R at main · marco2gandolfo/rcourse (github.com)

For more details on the usage of these functions please see the relevant sections within the R resources of this website.

For implementing the functions into R find additional information on the Readme of my github repository.
